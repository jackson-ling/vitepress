<h1 style="text-align: center; font-weight: bold;">System 类</h1>

---

## 常用方法

| 方法                                                                                                          | 描述                                                                |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| System.currentTimeMillis()                                                                                    | 返回当前时间距离 1970-1-1 的毫秒数                                  |
| System.arraycopy(<span style="color:red">源数组，源数组起始索引，目标数组，目标数组起始索引，拷贝长度</span>) | 复制数组元素，<span style="color:red">比较适合拷贝到指定位置</span> |
| System.exit()                                                                                                 | 退出当前程序                                                        |
| System.gc()                                                                                                   | 执行<span style="color:red">垃圾回收机制</span>                     |

## currentTimeMillis（）

> #### 返回当前时间距离 1970-1-1 的毫秒数

#### 代码示例

```java
public class main {
    public static void main(String[] args) {
        System.out.println(System.currentTimeMillis());
    }
}

// 输出结果
1749372542217
```

## arraycopy（）

> #### 复制数组元素，比较<span style="color:red">适合拷贝到指定位置</span>
>
> #### 使用方法：System.arraycopy（源数组，源数组<span style="color:red">起始索引</span>，目标数组，目标数组<span style="color:red">起始索引</span>，<span style="color:red">拷贝长度</span>）

#### 代码示例

```java
import java.util.Arrays;

public class main {
    public static void main(String[] args) {
        int[] arr = {1,2,3,4};
        int[] arr_new = new int[arr.length]; // 此时 arr_new 为 {0, 0, 0, 0}
        System.arraycopy(arr,0,arr_new,1,3);
        System.out.println(Arrays.toString(arr_new));
    }
}

// 输出结果
[0, 1, 2, 3]
```

#### 代码分析

> #### （1）源数组：arr
>
> #### （2）源数组拷贝的起始位置：0
>
> #### （3）目标数组：arr_new
>
> #### （4）目标数组拷贝的起始位置：1
>
> #### （5）拷贝长度：3

## exit（）

> #### 传入参数 <span style="color:red">0</span>：表示<span style="color:red">正常退出</span>

#### 代码示例

```java
public class main {
    public static void main(String[] args) {
        System.out.println("hello world");
        System.exit(0);
        System.out.println("程序继续执行...");
    }
}

// 输出结果
hello world
```

## gc（）

> #### （1）<span style="color:red">主动触发</span>垃圾回收机制，底层会<span style="color:red">默认调用 finalize（）</span>方法执行垃圾回收机制
>
> #### （2）<span style="color:red">垃圾回收</span>会在 JVM 内存使用达到<span style="color:red">某个阈值</span>时<span style="color:red">自动进行</span>。调用 <span style="color:red">System.gc( )</span> 可以请求 JVM 进行垃圾回收，但这<span style="color:red">只是一个建议</span>，JVM <span style="color:red">不一定会立即执行</span>垃圾回收操作

#### 代码示例

```java
public class finalize {
    public static void main(String[] args) {
        finals finals = new finals(18);
        finals = null;
        System.gc();
    }
}
class finals{
    int age;

    public finals(){

    }

    public finals(int age) {
        this.age = age;
    }

    @Override
    protected void finalize() throws Throwable {
        System.out.println("调用finalize回收对象");
    }
}

// 输出
调用finalize回收对象
```
