## 使用细节

### 三角函数

> #### 要求<span style="color:red">传入</span>的参数全部为<span style="color:red">弧度</span>，可以用 Math.toRadians（）方法把角度转为弧度

### 对数运算

> #### Math.log()：<span style="color:red">默认以 e 为底</span>

#### 计算其他数字为底的对数（使用<span style="color:red">换底公式</span>）

```java
public class time_test {
    public static void main(String[] args) {
        System.out.println(tool.log_x_n(2,2));
    }
}

class tool{
    public static double log_x_n(int x,int n){
        double temp1 = Math.log10(n);
        double temp2 = Math.log10(x);
        return temp1 / temp2;
    }
}
```

## ⭐ 任意随机数公式

> #### 获取 [a,b] 之间的随机数，公式：<span style="color:red"> (int ) (a + Math.random \* ( b - a + 1) )</span>

#### 案例：生成 2 <= x <= 7 之间的随机数

```java
for (int i = 0; i < 5; i++) {
    System.out.println((int)(2 + Math.random()*(7 - 2 + 1)));
}

// 输出结果
6
7
3
2
5
```

#### 推导过程

> #### （1）Math.random() \* 6 返回的是 0 <= x < 6 小数
>
> #### （2）2 + Math.random() \* 6 返回的就是 2 <= x < 8 小数
>
> #### （3）右边是无限接近于 8 的小数，最后<span style="color:red">取整</span>即可得到整数（右边界 7）
