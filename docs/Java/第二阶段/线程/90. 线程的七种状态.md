## 七种状态

### NEW

> #### 尚未启动的线程处于此状态

### RUNNABLE

> #### 在 Java 虚拟机中执行的线程处于此状态（<span style="color:red">又细分为两种状态</span>）
>
> #### （1）ready：预备状态
>
> #### （2）running：正在执行

### BLOCKED

> #### 被阻塞等待监视器锁定的线程处于此状态

### WAITING

> #### 正在等待另一个线程<span style="color:red">执行特定动作</span>的线程处于此状态

### TIMED WAITING

> #### 正在等待另一个线程<span style="color:red">执行动作直到指定时间</span>的线程处于此状态

### TERMINATED

> #### 已退出的线程处于此状态
