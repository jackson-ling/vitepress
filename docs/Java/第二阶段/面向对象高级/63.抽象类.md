<h1 style="text-align: center; font-weight: bold;">抽象类</h1>

---

### 基本介绍

> #### 引入关键字：<span style="color:red">abstract</span>
>
> #### 注意：<span style="color:red">只能修饰类和方法</span>，不能修饰属性和其它

#### 1. abstract 关键字修饰一个类时，这个类就叫<span style="color:red">抽象类</span>

#### 2. abstract 关键字修饰一个方法时，这个类就叫<span style="color:red">抽象方法</span>

> #### 注意点
>
> #### （1） 抽象方法<span style="color:red">没有方法体</span>
>
> #### （2）抽象方法不能使用 <span style="color:red">private、final 和 static</span> 来修饰，这些关键字都是<span style="color:red">和重写相违背的</span>
>
> #### private：私有的，访问权限上不允许，无法重写
>
> #### static：和重写无关的关键字
>
> #### final：不可以被修改，无法重写

```java
public abstract void hi();
```

#### 应用场景

#### （1）当子类中<span style="color:red">共有的部分 / 特性</span>可以放到抽象类中

#### （2） 通过<span style="color:red">子类重写抽象方法</span>实现不同的功能

#### （3） 在抽象类中编写一个方法，把共有的部分放入其中，在该方法中调用抽象方法（<span style="color:red">动态绑定机制</span>），同坐子类重写抽象方法，便可以实现不同类中共有的功能的同时还能实现自身的方法

#### （4） <span style="color:red">提高了代码的复用性</span>

#### （5） 面试中爱问，在框架和设计模式使用较多

## 代码示例

> #### 案例：两个子类的方法都需要提示程序的开始和结束，编写不同的数学方法

```java
package abstract_;

public class main {
    public static void main(String[] args) {
        a a = new a();
        a.show();
        System.out.println("------------------------------------");
        b b = new b();
        b.show();
    }
}

abstract class shared {

    public abstract void tool(int a, int b); // 抽象方法不可以有方法体

    public void show() {
        System.out.println("你进入了抽象类的show方法：开始执行");
        tool(2,3);
        System.out.println("你退出了抽象类的show方法：执行结束");
    }
}


class a extends shared {

    public void tool(int a, int b) {
        System.out.println("a + b = " + (a + b));
    }
}

class b extends shared {
    public void tool(int a, int b) {
        System.out.println("a * b = " + (a * b));
    }
}

//输出结果
你进入了抽象类的show方法：开始执行
a + b = 5
你退出了抽象类的show方法：执行结束
------------------------------------
你进入了抽象类的show方法：开始执行
a * b = 6
你退出了抽象类的show方法：执行结束
```

#### 代码解析

#### （1） 代码实现的核心：<span style="color:red">动态绑定机制和继承关系</span>

#### （2） 两个数学方法都需要再方法执行的开头和结尾提示信息，<span style="color:red">共有的部分</span>放入<span style="color:red">抽象类</span>中的方法中

#### （3） 子类通过重写抽象方法 tool ( ) 实现不同的功能

#### （4）动态绑定机制的实现过程（以 a 对象为例）

> #### 1. 首先明确继承关系，创建 a 对象时，区别编译类型和运行类型
>
> #### 2. show（）方法在本类（a 类）中没有，寻找父类，调用父类中的 show（）方法
>
> #### 3. show（）方法中调用了 tool（）方法，根据动态绑定机制，则调用 a 对象的 tool（） 方法

## 使用细节

#### （1）<span style="color:red">抽象类不能实例化</span>（不可以创建一个抽象类对象）

#### （2）抽象类不一定要包含 abstract 方法。也就是说，抽象类<span style="color:red">可以没有 abstract 方法</span>

#### （3）一旦类<span style="color:red">包含了 abstract 方法</span>，则这个<span style="color:red">类必须声明为 abstract</span>

#### （4）抽象类可以有任意成员（抽象类本质还是类），比如：非抽象方法、构造器、静态属性等等

## ⭐ 模板设计模式

#### （1）基本介绍：抽象类体现的就是一种模板模式的设计，抽象类<span style="color:red">为多个子类提供的通用模板</span>，子类在抽象类<span style="color:red">模板的基础上进行扩展、改造</span>，但子类总体上会保留抽象类的行为方式。

#### （2）实际应用

> #### 1. 当功能内部一部分实现是确定的，一部分实现是不确定的时候，可以把不确定的部分暴露出去，让子类去实现。
>
> #### 2. 编写一个抽象父类，父类提供了多个子类的通用方法，并把一个或多个方法留给其子类实现，这就是一种模板模式
