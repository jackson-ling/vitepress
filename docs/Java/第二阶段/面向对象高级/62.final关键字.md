<h1 style="text-align: center; font-weight: bold;">final 关键字</h1>

---

## 基本介绍

> #### final 可以修饰<span style="color:red">类、属性、方法和局部变量</span>（<span style="color:red">final 不能修饰构造器</span>）
>
> #### （1）修饰<span style="color:red">属性</span>时：表示该属性<span style="color:red">不能被修改</span>
>
> #### （2）修改<span style="color:red">方法</span>时：表示该方法<span style="color:red">不能被重写</span>
>
> #### （3）修改<span style="color:red">类</span>时：表示该方法<span style="color:red">不能被继承</span>

#### 使用场景

#### （1）类不能被继承时，可以使用 final 修饰

#### （2）类的某个属性不可以被更改，可以使用 final 修饰

#### （3）父类的某个方法不能被子类重写，可以使用 final 修饰

#### （4）某个局部变量不能被修改，可以使用 final 修饰

> #### 1. 可以是<span style="color:red">循环中</span>的局部变量
>
> #### 2. 可以是<span style="color:red">方法中</span>的局部变量

## 使用细节

#### （1）final 修饰的属性又叫<span style="color:red">常量（全部大写）</span>，一般用<span style="color:red"> XX_XX_XX</span> 来命名

#### （2）final 修饰的属性在<span style="color:red">定义时，必须赋初值</span>，并且以后不能再修改，赋值可以在如下位置之一

> #### 1. 在<span style="color:red">定义</span>时
>
> #### 2. 在<span style="color:red">代码块</span>中
>
> #### 3. 在<span style="color:red">构造器</span>中

#### （3）如果 final 修饰的<span style="color:red">属性</span>是<span style="color:red">静态</span>的（<span style="color:red">不能在构造器中赋值</span>），则初始化的<span style="color:red">位置只能是</span>

> #### 1. 在<span style="color:red">定义</span>时
>
> #### 2. 在<span style="color:red">静态代码块</span>中

#### （4）final 类<span style="color:red">不能继承</span>，但是<span style="color:red">可以实例化对象</span>（可以创建一个 final 类的对象）

#### （5）如果类不是 final 类，但是含有 <span style="color:red">final 方法</span>，则该方法<span style="color:red">不能重写</span>

#### （6）代码规范：如果一个类已经是 final 类了，就没有必要再将该类中的方法修饰成 final 方法了

#### （7）包装类（Integer、Double、Float、Boolean 等都是 final），<span style="color:red">String 也是 final 类</span>（不可变）

#### （8）final <span style="color:red">和 static 往往搭配使用</span>，效率更高，<span style="color:red">不会导致类加载</span>（底层编译器做了优化处理）

> #### 1. static final 变量表示该变量属于哪个类，而不是某个实例
>
> #### 2. 当 <span style="color:red">final 和 static 一起使用</span>时，通常用于<span style="color:red">声明常量</span>（这里表示类常量），该常量值在类的所有实例中共享，且不可修改

#### 为什么不会导致类加载？

> #### （1） 编译器将 static final 的<span style="color:red">常量值</span>直接<span style="color:red">存储到</span>调用类的<span style="color:red">常量池</span>中
>
> #### （2） 使用该常量时，<span style="color:red">JVM 直接使用常量池中的值，不需要访问定义常量的类</span>，自然就<span style="color:red">不会导致类的加载</span>，提高了效率

## 代码示例

```java
package final_;

public class main {
    public static void main(String[] args) {
        System.out.println(A.a);
    }
}

class A{
    public final static int a = 10;

    static {
        System.out.println("代码块被调用");
    }

    public A(){
        System.out.println("构造器被调用");
    }
}

// 输出结果
10
```

#### 代码分析

> #### final 和 static 搭配使用修饰一个属性，调用该属性时不会导致类的加载，即不会执行代码块中的内容
