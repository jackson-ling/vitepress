<div style="font-size:20px">
    1. 简单好用，增强功能
    <ul>
        <ul>
            <li>Chinese Language Pack：中文语言包</li>
            <br/>
            <li>Translation：翻译插件，鼠标选中文本，点击右键即可自动翻译成多国语言（<span style="color:red;font-weight:bold">需要申请API</span>）</li>
            <br/>
            <li>Key Promoter X：快捷键提示插件。当你执行鼠标操作时，如果该操作可被快捷键代替，会给出提示，帮助你自然形成使用快捷键的习惯，告别死记硬背</li>
            <br/>
            <li>Rainbow Brackets：给括号添加彩虹色，使开发者通过颜色区分括号嵌套层级，便于阅读</li>
            <br/>
            <li>CodeGlance：在编辑器右侧生成代码小地图，<span style = "color:red;font-weight:bold">快捷键：ctrl + shift + g</span> 用于快速开启或者关闭小地图</li>
            <br/>
            <li>Statistic：代码统计</li>
        </ul>
    </ul>
    <br/>
    2. 提高开发效率和代码质量
    <ul>
        <ul>
            <li>Lingma - Alibaba Cloud AI Coding Assistant：通义灵码插件</li>
            <br/>
            <li>Alibaba Java Coding Guidelines：代码规范检查插件</li>
            <br/>
            <li>JavaDoc：生成 Javadoc 文档（选取代码片段，<span style = "color:red;font-weight:bold">快捷键：alt + insert</span> 生成 JavaDoc 文档）</li>
            <br/>
            <li>GenerateAllSetter：快速生成调用对象 setter 方法的代码</li>
            <br/>
            <li>GenerateSerialVersionUID：一键为实现 Serializable 接口的类生成 SerialVersionUID</li>
            <br/>
            <li>GsonFormatPlus：根据 json 生成对象，<span style = "color:red;font-weight:bold">alt + s</span> 呼出菜单</li>
            <br/>
            <li>JUnitGenerator V2.0：自动生成单元测试</li>
            <br/>
            <li>jclasslib Bytecode Viewer：字节码查看器</li>
            <br/>
            <li>String Manipulation：字符串快捷处理，<span style = "color:red;font-weight:bold">alt + m</span> 呼出菜单</li>
            <br/>
            <li><span style = "color:red;font-weight:bold">MybatisX</span>：支持<span style = "color:red;font-weight:bold">生成</span> entity、mapper、service 等常用操作的<span style = "color:red;font-weight:bold">代码</span></li>
            <br/>
            <li><span style = "color:red;font-weight:bold">Apifox Helper</span>：接口自动识别，测试插件</li>
            <br/>
            <li>RestfulTool：项目接口预览插件，支持查看请求参数，请求体</li>
            <br/>
            <li>AceJump：光标快速跳转插件（ 教程视频：<a href="https://www.bilibili.com/video/BV1ZD421p7Ci/" target="_blank">https://www.bilibili.com/video/BV1ZD421p7Ci/</a> ）</li>
            <br/>
            <li>MybatisLog：将控制台输出的 sql 日志直接转为可执行的 sql 语句</li>
            <br/>
            <li>Maven Helper：打开 pom 文件，更方便的查看依赖关系</li>
            <br/>
            <li>Sequence Diagram：根据代码生成时序图，查看方法间的调用顺序和关系，还可以导出为图片或者 UML 类图</li>
            <br/>
            <li>GitToolBox：Git 插件，可以看见每行代码是谁修改的</li>
            <br/>
            <li>Json Parser：JSON 解析插件，支持格式化、校验、转换等操作，默认采用 JDK 17 编译，需要<span style = "color:red;font-weight:bold">高版本的 IDEA</span></li>
        </ul>
    </ul>
    3. 其他
    <ul>
        <ul>
            <li>Leetcode Editor：在 IDEA 里刷算法题</li>
            <br/>
            <li>GitToolBox： Git 增强插件。在自带的 Git 功能之上，新增了查看 Git 状态、自动拉取代码、提交通知等功能。最好用的是可以查看到每一行代码的最近一次提交信息</li>
            <br/>
            <li>BashSupport：支持 Bash 脚本文件的高亮和提示等</li>
            <br/>
            <li>CSV：支持 CSV 文件的高亮和提示等</li>
            <br/>
            <li>Nyan Progress Bar：彩虹进度条美化</li>
            <br/>   
            <li>Grep Console：控制台日志输出辅助插件</li>
        </ul>
    </ul>
</div>
