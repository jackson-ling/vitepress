<h1 style="text-align: center; font-weight: bold;">链表相加</h1>

---

## 题目链接

> #### https://leetcode.cn/problems/add-two-numbers/description/
>
> #### 给你两个非空的链表，表示两个非负的整数，它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字，请你将两个数相加，并以相同形式返回一个表示和的链表，你可以假设除了数字 0 之外，这两个数都不会以 0 开头

## 思路分析

> #### 用三个指针操作链表，完成节点的遍历和挂接，在遍历的过程中需要考虑指针是否为空的情况
>
> #### 关键在于如何表示进位，如果两数之和大于 10，该如何挂接节点

## 代码实现

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // 定义结果链表的相关变量
        ListNode ans = null;
        ListNode cur = null;

        // 用于标记进位
        int carry = 0;

        // 遍历两个链表
        while (l1 != null || l2 != null) {
            int sum = (l1 == null ? 0 : l1.val)
                    + (l2 == null ? 0 : l2.val)
                    + carry;

            int val = sum % 10;
            carry = sum / 10;

            // 在新链表上挂接节点
            if (ans == null) {
                ans = new ListNode(val);
                cur = ans;
            } else {
                cur.next = new ListNode(val);
                cur = cur.next;
            }

            // 移动两个链表的指针
            l1 = l1 == null ? null : l1.next;
            l2 = l2 == null ? null : l2.next;
        }

        // 判断是否有进位，挂接节点 1
        if (carry == 1) {
            cur.next = new ListNode(1);
        }
        return ans;
    }
}
```
