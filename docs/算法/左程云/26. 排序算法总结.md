<h1 style="text-align: center; font-weight: bold;">排序算法总结</h1>

---

## 稳定性

> #### 排序算法的稳定性是指<span style="color:red">同样大小的样本在排序之后不会改变原始的相对次序</span>

## 排序总结

| **排序算法**                                        | **时间复杂度** | **空间复杂度**                        | **稳定性**                        |
| --------------------------------------------------- | -------------- | ------------------------------------- | --------------------------------- |
| 选择排序 (SelectionSort)                            | O（N²）        | O（1）                                | 无                                |
| 冒泡排序 (BubbleSort)                               | O（N²）        | O（1）                                | <span style="color:red">有</span> |
| 插入排序 (InsertionSort)                            | O（N²）        | O（1）                                | <span style="color:red">有</span> |
| <span style="color:red">归并排序</span> (MergeSort) | O（N \* logN） | <span style="color:red">O（N）</span> | <span style="color:red">有</span> |
| <span style="color:red">快速排序</span> (QuickSort) | O（N \* logN） | O（logN）                             | 无                                |
| <span style="color:red">堆排序</span> (HeapSort)    | O（N \* logN） | <span style="color:red">O（1）</span> | 无                                |
| 计数排序 (CountSort)                                | O（N）         | O（M）                                | <span style="color:red">有</span> |
| 基数排序 (RadixSort)                                | O（N）         | O（M）                                | <span style="color:red">有</span> |

## 选择策略

> #### （1）<span style="color:red">数据量非常小</span>的情况下可以做到非常迅速：<span style="color:red">插入排序</span>
>
> #### （2）性能优异、实现简单且利于改进（面对不同业务可以选择不同划分策略）、不在乎稳定性：<span style="color:red">随机快排</span>
>
> #### （3）性能优异、不在乎额外空间占用、具有稳定性：<span style="color:red">归并排序</span>
>
> #### （4）性能优异、额外空间占用要求 O（1）、不在乎稳定性：<span style="color:red">堆排序</span>
