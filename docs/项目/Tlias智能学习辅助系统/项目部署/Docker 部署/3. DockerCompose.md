<h1 style="text-align: center;">DockerCompose</h1>

---

## 需求分析

> #### 实际开发中会有很多个容器，且存在依赖和先后关系，这里采用 DockerCompose 可实现一键配置与部署，简化部署过程

## 实现步骤

#### （1）在 Linux 服务器的 /usr/local 目录下创建目录 app，并切换到 /usr/local/app 目录。

#### （2） 上传资料中提供的 "资料/05. Docker Compose" 中的文件及文件夹到 /usr/local/app 目录中

> #### <span style="color: red;">注意：资料中提供的 Dockerfile 文件中的阿里云 OSS 的 AccessKeyId，AccessKeySecret 需要替换成自己的</span>

#### （3）执行如下指令，基于 DockerCompose 部署项目

```bash
docker compose up -d
```
