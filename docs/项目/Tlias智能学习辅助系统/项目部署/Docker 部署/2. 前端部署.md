<h1 style="text-align: center;">前端部署</h1>

---

## 需求分析

### 需求

> #### 创建一个新的 nginx 容器，将资料中提供的前端项目的静态资源部署到 nginx 中。

### 步骤

#### （1）在宿主机上准备静态文件及配置文件存放目录(在 /usr/local 目录下创建 tlias-web 目录)

```bash
创建 nginx 容器 ：-v /usr/local/tlias-web/html:/usr/share/nginx/html
创建 nginx 容器 ：-v /usr/local/tlias-web/conf/nginx.conf:/etc/nginx/nginx.conf
```

#### （2）部署 nginx 容器

## 具体实现

#### （1）部署 nginx 容器（设置目录映射）

> #### 将资 资料/04. 项目部署/前端项目 中的 目录 html 和 配置文件存放目录 conf，上传至服务器端的 /usr/local/tlias-web 目录下

#### （2）执行如下命令，部署 nginx 容器

```bash
docker run -d \
--name nginx-tlias \
-v /usr/local/tlias-web/html:/usr/share/nginx/html \
-v /usr/local/tlias-web/conf/nginx.conf:/etc/nginx/nginx.conf \
--network itheima \
-p 80:80 \
nginx:1.20.2
```

#### （3）前后端都部署完毕后，就可以打开浏览器，来测试一下。访问前端的 nginx 服务器
