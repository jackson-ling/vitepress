### 接口设计规范

#### （1）请求路径命名：以模块名称进行区分（英文）

#### （2）请求方式（需要符合 restFul 风格）

> #### 查询 GET
>
> #### 新增 POST
>
> #### 修改 PUT
>
> #### 删除 DELETE

#### （3）接口入参

#### 路径参数

> #### 问号传参---->后端形参接收
>
> #### path 传参---->后端 PathVariable 注解接收

#### 请求体参数

> #### 前端：json 对象
>
> #### 后端：对象接收，DTO

#### （4）接口出参

> #### 统一格式 { code:200,msg:"成功",data:{ } }
>
> #### 数据封装，一般为 VO
>
> #### （1）敏感数据过滤
>
> #### （2） 整合数据
